Parking Lot, Entry to Exit Flow
* Vehicles take a ticket, drive to a matching spot, then pay at the booth and exit.

Functional Requirement - (reason to exist)  
1. support multiple parking floors
2. support multiple vehicle types
3. classify parking spot by size
4. issue parking ticket upon entry and track exist time 
5. calculate parking fee
6. query and display parking spots.
7. use demo class to simulate.
